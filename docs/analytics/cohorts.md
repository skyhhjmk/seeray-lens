# Cohort analysis

The site-level **Cohorts** report groups anonymous visitors by either the local calendar day, week or month of their first meaningful session or their first conversion of a selected enabled goal. A meaningful session has at least one page view or one non-heartbeat event. A visitor is counted as retained in a later period when a meaningful session starts in that period, regardless of which cohort basis was selected.

The report API is:

```text
GET /api/v1/sites/{siteId}/analytics/cohorts?from=YYYY-MM-DD&to=YYYY-MM-DD&period=week&periods=8&basis=first_visit&metric=returning_visitors&segmentId={optional}
```

`period` accepts `day`, `week` (the default), `month`, `year`, or `custom`; `periods` accepts 7, 14, or 30 for days, 4, 8, or 12 for weeks, 3, 6, or 12 for months, 2, 3, 5, or 10 for years, and 2, 4, 8, or 12 for custom periods. For `period=custom`, `periodDays` sets a consecutive local-calendar-day bucket length from 1 to 365 (default 14); custom buckets align to the selected `from` date, so changing the report start also changes the bucket boundaries. The old `weeks` query parameter remains accepted as a weekly compatibility alias. Cohort reports accept an inclusive reporting range of up to 3660 days; other analytics reports retain their 366-day limit. `basis` accepts `first_visit` (the default) or `goal_conversion`; the latter requires a site-scoped enabled `goalId`. `metric` accepts `returning_visitors` (the default), `visits`, `goal_conversions`, or `goal_value`. `goal_conversions` requires a separate site-scoped enabled `metricGoalId`; `goal_value` sums fixed values for all matching conversions of enabled site goals and does not require a goal selector. Keeping `goalId` and `metricGoalId` separate allows (for example) first-visit cohorts to be measured by a later signup goal. Visit counts include meaningful sessions that started at or after the exact cohort-entry timestamp and through the report end date. Goal events use the matched event's analytics timestamp after the normal clock-skew correction and are likewise counted only from cohort entry onward. Each response row contains the cohort period start date, period index, original cohort size, retained visitor count, retention rate, meaningful visit count, goal conversion count, unique goal-converting visitor count, summed fixed goal value, and whether the observation period is complete. For `goal_conversions`, the fixed value belongs to the selected goal; for `goal_value`, it is summed across enabled goals. Period 0 is the full cohort by definition for returning visitors; visit and goal metrics count actual activity in that period. Later day, week, month, year, and custom-period cells are complete only when the entire local calendar bucket ends on or before the selected report end date. The Admin matrix displays incomplete periods as a dash instead of treating partial data as poor retention.

The selected date range filters visitors by the local date of the selected cohort event: the first meaningful session or the first matching goal conversion. Return activity is observed through the selected end date, including sessions that cross a report-period boundary. A saved segment, when selected, is evaluated against each visitor's cohort-defining session (first meaningful session or first goal-conversion session); it filters cohort membership, not subsequent return activity.

The Admin navigation is **Visitors → Cohorts**. The view offers independent cohort-basis and measurement selectors (returning visitors, visits, goal conversions, or aggregate goal value), configured-goal selectors when a specific goal is being measured (with a shortcut to goal management), daily/weekly/monthly/yearly grouping, a custom-period option with a 1–365 day slider, unit-appropriate observation windows, and the shared site date and segment selectors. Cohort dates can be selected over a custom range of up to 3660 days. A weighted trend chart summarizes the selected metric across mature cohort periods; it excludes incomplete periods and normalizes visits and fixed goal value per original cohort visitor. Goal conversion cells show the share of the original cohort that converted; their tooltip includes event count and that goal's fixed value. Goal-value cells sum the configured fixed values of all enabled goals and explicitly do not represent ecommerce revenue or a currency-converted amount. Visit cells show the number of meaningful sessions, not unique visitors. It defaults an untouched real-time range to the last 12 weeks so the cohort matrix is useful on first open. The report returns aggregate counts only and does not expose visitor identifiers.
