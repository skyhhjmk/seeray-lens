# Cohort analysis

The site-level **Cohorts** report groups anonymous visitors by either the local calendar day, week or month of their first meaningful session or their first conversion of a selected enabled goal. A meaningful session has at least one page view or one non-heartbeat event. A visitor is counted as retained in a later period when a meaningful session starts in that period, regardless of which cohort basis was selected.

The report API is:

```text
GET /api/v1/sites/{siteId}/analytics/cohorts?from=YYYY-MM-DD&to=YYYY-MM-DD&period=week&periods=8&basis=first_visit&metric=returning_visitors&segmentId={optional}
```

`period` accepts `day`, `week` (the default), or `month`; `periods` accepts 7, 14, or 30 for days, 4, 8, or 12 for weeks, and 3, 6, or 12 for months. The old `weeks` query parameter remains accepted as a weekly compatibility alias. `basis` accepts `first_visit` (the default) or `goal_conversion`; the latter requires a site-scoped enabled `goalId`. `metric` accepts `returning_visitors` (the default) or `goal_conversions`; goal conversion measurement requires a separate site-scoped enabled `metricGoalId`. Keeping `goalId` and `metricGoalId` separate allows (for example) first-visit cohorts to be measured by a later signup goal. Goal events use the matched event's analytics timestamp after the normal clock-skew correction. Each response row contains the cohort period start date, period index, original cohort size, retained visitor count, retention rate, goal conversion count, unique goal-converting visitor count, summed fixed goal value, and whether the observation period is complete. Period 0 is the full cohort by definition for returning visitors; goal metrics count actual goal events in that period. Later day, week and month cells are complete only when the entire local calendar period ends on or before the selected report end date. The Admin matrix displays incomplete periods as a dash instead of treating partial data as poor retention.

The selected date range filters visitors by the local date of the selected cohort event: the first meaningful session or the first matching goal conversion. Return activity is observed through the selected end date, including sessions that cross a report-period boundary. A saved segment, when selected, is evaluated against each visitor's cohort-defining session (first meaningful session or first goal-conversion session); it filters cohort membership, not subsequent return activity.

The Admin navigation is **Visitors → Cohorts**. The view offers independent cohort-basis and measurement selectors, configured-goal selectors (with a shortcut to goal management), daily/weekly/monthly grouping, unit-appropriate observation windows, and the shared site date and segment selectors. Goal conversion cells show the share of the original cohort that converted; their tooltip includes event count and summed fixed goal value. It defaults an untouched real-time range to the last 12 weeks so the retention matrix is useful on first open. Cohort periods longer than a month (for example, yearly cohorts) are not yet supported because analytics date ranges are currently limited to 366 days. The report returns aggregate counts only and does not expose visitor identifiers.
